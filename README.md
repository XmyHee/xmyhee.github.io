# Quest Frontiers · 求索前沿

Quester 的个人研究主页。围绕运行时契约、确定性、权威边界与证据追溯展开研究。

## 文件

- `index.html`：项目概览、契约与边界、验证依据三个页面区域。
- `style.css`：深海军蓝与青色视觉，包含移动端布局和减少动态效果偏好。
- `script.js`：研究方向展开、审计方法切换、导航状态、内容依据弹窗。
- `assets/quest-frontiers-mark.svg`、`favicon.svg`：依据提供的品牌概念重绘的矢量标志。
- `CNAME`：保留现有的 `questfrontiers.com` 域名配置。

无需构建或外部脚本依赖，直接使用仓库根目录静态文件。可运行 `python -m http.server 8080` 进行本地预览。

## 内容边界

页面介绍研究关注与工作原则，不构成项目合规性验证结论。网站视觉依据用户提供的「求索前沿品牌概念提案」。
